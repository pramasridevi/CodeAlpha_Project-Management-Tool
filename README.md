# ConnectHub – Modern Project Management Platform
## Overview

ConnectHub is a modern web-based project management platform built to help teams organize projects, manage tasks, monitor progress, and improve collaboration. The application provides an intuitive user interface that enables users to efficiently plan and execute projects from start to finish.

The project was developed using modern web technologies and follows a scalable architecture suitable for real-world project management workflows.

---

## Features

### Project Management

* Create and manage multiple projects
* Organize project workflows efficiently
* Track project status and milestones

### Task Tracking

* Create, update, and manage tasks
* Monitor task completion progress
* Improve productivity through structured workflows

### Team Collaboration

* Centralized workspace for project teams
* Better communication and coordination
* Shared visibility across projects

### Modern User Interface

* Responsive design for desktop and mobile devices
* Clean and intuitive user experience
* Fast performance powered by Vite

## Installation

### Clone the Repository

```bash
git clone https://github.com/pramasridevi/Project-Management-Tool.git
```

### Navigate to the Project Directory

```bash
cd Project-Management-Tool
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Open in Browser

Visit the local URL displayed in the terminal after starting the development server.
